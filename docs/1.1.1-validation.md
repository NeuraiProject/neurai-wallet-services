# 1.1.1 validation — 2026-09-21

Implemented against service base `ceb47c3` and the current NeuraiWallet working
tree. No commit, tag, publication or deployment was made.

## Automated evidence

- `npm test -- --runInBand`: **17 suites, 162 tests passed**. Covers signed
  amounts, bounded/canonical input, schema encoding, real HTTP forwarding,
  typed cache keys, cache replacement, node identity/failover, negotiation,
  subscription rollback/caps, pagination, mixed sessions, stale/recovery and
  the literal pre-migration status hash.
- `npm ci --ignore-scripts`: lockfile installs successfully.
- Docker image built from this local checkout with the updated Dockerfile;
  its dependency layer runs `npm ci --omit=dev` without fallback.
- Both mainnet and testnet compose configurations pass `config --quiet`.
- NeuraiWallet: **45 unit tests in 3 suites passed** (backend amounts, wallets,
  hardware amount adapters); TypeScript `--noEmit` passed; changed application
  files passed ESLint after formatting.
- Real app/service/node acceptance: **4 tests passed**, including odd raw
  amount `10000000000000001`, empty/funded PQ, legacy→PQ, PQ signing, a 1 XNA
  spend, send-max above 2^53, send-many, assets units 0/2/8, admission,
  broadcast, confirmation, input/output/fee equality, mixed v1/v2 mempool and
  block pushes, and uncached gettxout after a mempool spend.
- The separate raw service probe passed simple/bulk/state, default/unknown
  protocol, exact HTTP cache hits and raw decimal createrawtransaction
  forwarding checked against the node's decoded transaction.

## Isolated acceptance environment

The existing `nw-bigint-proof` regtest volume was reused. Port 19211 belonged
to `nw-bigint-npm`, so the proof project used **19213**, without stopping or
modifying that other project. Service: `127.0.0.1:19220`, polling enabled, ZMQ
disabled, one local upstream, explicit regtest genesis and service identity.
All app HTTP calls were restricted to the local companion service. Node CLI
calls were restricted to the proof compose project. This execution mined
blocks and spent only regtest outputs in that proof volume.

Machine-local scripts under `NeuraiWallet/tmp/`:

- `bigint-services-run.cjs`: current checkout, injected isolated configuration;
- `bigint-wss-acceptance.test.ts`: real app construction, signing and sends;
- `bigint-service-client.cjs`: test WebSocket client;
- `bigint-common.cjs`: now accepts `BIGINT_RPC_PORT` (default 19211).

Service probe: `tmp/bigint-services-acceptance.cjs`. The app test writes
`tmp/bigint-fixture.json` with public addresses, txid/vout and string amounts.
That fixture is checked before the probe and deliberately spent later in the
same acceptance test; do not reuse it as an unspent fixture after this run.
The funding helper requires enough first-era subsidy UTXOs; do not repeatedly
mine the existing volume past its guard. A later full run needs a prepared
fixture or a separately named fresh isolated project, never deletion of the
existing volume to make a test pass.

Logs copied into service `tmp/`: `services-unit.log`,
`app-services-unit.log`, `app-services-acceptance.log`,
`app-services-tsc.log`, and `services-docker-build.log`.

## Limits and deployment configuration

This is desktop Node/regtest evidence. No physical mobile device, hardware
signer, public service or external webwallet was tested or deployed. The
hardware tests above exercise adapters, not a physical device. No claim of
complete PLAN-03 device acceptance is made.

Configure a stable, deployment-specific `service_id` and the companion HTTP
endpoint before rolling out the app's pairing validation. Existing anonymous
HTTP remains supported; WSS authentication is unchanged. Asset pending amounts
remain unqueried and are explicitly advertised as unsupported. Legacy v1
remains available; these tests do not authorize its retirement.
